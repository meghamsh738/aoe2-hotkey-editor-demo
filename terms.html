What the editor provides

The editor is a local utility for inspecting, editing, comparing, practicing, and exporting Age of Empires II: Definitive Edition hotkey bundles. It is not affiliated with or endorsed by Microsoft or the Age of Empires team.

Your files and exports

You are responsible for the profiles you open, the changes you make, and the exported files you put back into the game. Keep an original backup before replacing a profile. Verify an export in-game before relying on it in a competitive match.

No guarantee of game behavior

Game updates, mods, hardware, operating systems, and browser behavior can change how a hotkey behaves. The synthetic demonstration profile and the editor’s classifications are guidance, not a guarantee that every assignment will work in every game state.

Changes and feedback

The project may change or be unavailable without notice. You can suggest fixes or report issues through the GitHub feedback forms.
